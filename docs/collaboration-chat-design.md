## 一、数据结构设计

### 1. 对话消息类型
```typescript
interface ConversationMessage {
  id: string;                    // 消息ID
  delegationId: string;          // 关联的任务ID
  sender: string;                // 发送者 (delegator/delegatee)
  content: string;               // 消息内容
  timestamp: number;             // 时间戳
  type: 'text' | 'instruction' | 'feedback' | 'system';  // 消息类型
  read: boolean;                 // 是否已读
}
```

## 二、核心功能模块

### 1. **任务接受流程** (被委托者视角)
```
pending → accepted
├─ 显示任务详情
├─ 显示验收标准、期望交付物
├─ 提供 "接受/拒绝" 选项
└─ 接受后进入执行阶段
```

### 2. **任务执行阶段** (被委托者执行)
```
accepted → in_progress
├─ 自动开始执行
├─ 实时显示执行进度 (日志、文件创建、命令执行)
├─ 委托者可以看到进度
└─ 执行完成后 → pending_review
```

### 3. **协作对话阶段** (双方实时对话)
```
任务详情页面
├─ 显示对话历史
├─ 实时消息输入
├─ 系统消息 (状态变更、执行进度等)
└─ 未读消息提醒
```

### 4. **验收阶段** (委托者视角)
```
pending_review
├─ 显示执行结果
├─ 提供验收选项 (通过/驳回)
├─ 驳回时提供反馈
└─ 通过后 → completed
```

### 5. **驳回重试流程**
```
pending_review → accepted (新一轮)
├─ 显示驳回反馈
├─ 自动重新执行
└─ 带着反馈重新开始
```
