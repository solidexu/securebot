# 删除委派任务功能说明

## 功能概述

委托者可以删除自己委派出去的任务。

## 使用方法

### 方式1：指定任务ID删除
```bash
/collab delete <delegation-id>
```

### 方式2：交互式选择删除
```bash
/collab delete
```

系统会列出所有可删除的任务，让你选择。

## 权限规则

1. **只有委托者可以删除**：被委托者无法删除收到的任务
2. **状态限制**：只能删除以下状态的任务
   - `pending` - 待接受
   - `accepted` - 已接受
   - `rejected` - 已拒绝
   - `completed` - 已完成
   - `failed` - 已失败
   - `pending_review` - 待验收
   - `in_progress` - 执行中（称为"中止"）

3. **执行中的任务可以中止**：状态为 `in_progress` 的任务可以中止执行

## 操作说明

### 中止正在执行的任务

当任务状态为 `in_progress` 时，操作菜单会显示"中止任务"选项：

```
操作选项:
  c. 中止任务
  q. 返回列表
```

选择"中止任务"会：
1. 停止任务执行
2. 从执行队列中移除
3. 删除任务记录
4. 通知被委托者任务已取消

## 通知机制

删除任务后，系统会自动通知被委托者：

- **pending/accepted 状态**：被委托者会收到"任务已被委托者取消"的通知
- **completed/failed 状态**：不会发送通知（任务已结束）

## 实现细节

### 数据删除
1. 从内存中移除委派记录
2. 从执行队列中移除（如果在队列中）
3. 删除持久化文件

### 代码示例

```typescript
// 删除委派
await collaborationManager.getDelegationManager().deleteDelegation(
  delegationId,
  state.currentAgentId
);
```

## 使用场景

1. **任务不再需要**：委托者取消任务
2. **任务分配错误**：误操作需要撤回
3. **清理历史任务**：删除已完成/失败的任务记录

## 注意事项

- 删除操作不可恢复
- 删除 `pending` 或 `accepted` 状态的任务会通知被委托者
- 不能删除正在执行的任务（需等待执行完成或中止）
- 删除后相关的执行历史和验收历史也会一并删除

## 相关命令

- `/collab tasks` - 查看所有任务
- `/collab history` - 查看任务历史
- `/collab delegate` - 创建新委派
