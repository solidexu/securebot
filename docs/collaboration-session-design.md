# 协作会话系统设计方案

## 设计理念
**以任务为核心**，而不是以每个 agent 为核心。委托者和被委托者围绕任务进行协作。

## 核心特性

### 1. 接受任务方式

**场景 A：被委托者在另一个窗口（已实现）**
```bash
# 窗口1：委托者 dev
/collab → 选择任务 → 进入协作会话

# 窗口2：被委托者 py
/collab → 看到任务 → 按 a 接受

# 协作会话中实时显示：
[系统] py 已接受任务 ✅
```

### 2. 任务执行方式

**被委托者后台自动执行**

```typescript
// 执行引擎
class TaskExecutor {
  async execute(delegation: DelegationRequest): Promise<void> {
    // 1. 发送开始执行消息到协作会话
    await session.sendMessage('system', '开始执行任务...', 'status_update');
    
    // 2. 加载被委托者 agent
    const agent = loadAgent(delegation.delegatee);
    
    // 3. 执行过程中实时推送日志
    agent.on('tool_call', (tool) => {
      session.sendMessage('system', `调用工具: ${tool.name}`, 'execution_log');
    });
    
    agent.on('file_created', (file) => {
      session.sendMessage('system', `创建文件: ${file.path}`, 'execution_log');
    });
    
    // 4. 执行完成
    await session.sendMessage('system', '任务执行完成', 'status_update');
  }
}
```

### 3. 多窗口同步机制

**文件监听实时同步**

```typescript
import chokidar from 'chokidar';

class CollaborationSync {
  private watcher: chokidar.FSWatcher;
  
  startWatching(delegationId: string, callback: () => void) {
    const delegationFile = `~/.securebot/collaboration/delegations/${delegationId}.json`;
    
    this.watcher = chokidar.watch(delegationFile, {
      ignoreInitial: true,
      awaitWriteFinish: {
        stabilityThreshold: 100,
        pollInterval: 50
      }
    });
    
    this.watcher.on('change', () => {
      // 文件变化，触发界面刷新
      callback();
    });
  }
}
```
