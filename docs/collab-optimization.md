# /collab 命令优化说明

## 改进内容

### 1. 默认行为优化
- **`/collab`** 现在默认进入任务管理面板
- 无需输入 `/collab tasks`，直接使用 `/collab` 即可

### 2. 集成的任务管理面板

进入 `/collab` 后，你会看到：

```
📋 任务管理面板
═══════════════════════════════════════════════════════════
  委派出去: 3 个 | 收到委派: 2 个
  ⏳ 待验收: 1 个任务
═══════════════════════════════════════════════════════════

  【委派出去的任务】
    [1] ⏳  待验收 10:30:00 → py 实现光流算法...
    [2] ✓ 09:58:50 → dev 测试用户登录...
    [3] ✗ 08:30:00 → py 优化查询性能...

  【收到委派的任务】
    [4] 🔄 11:00:00 ← dev review代码...
    [5] ● 10:45:00 ← py 编写测试用例...

────────────────────────────────────────────────────────────
  序号=查看详情 | n=新建委派 | q=退出
  提示: 有 1 个任务待验收
```

### 3. 任务详情页面的集成操作

选中任务后，可以：

```
📋 任务详情
═══════════════════════════════════════════════════════════

  任务: 实现光流算法
  ID: effd2650
  角色: 委派者 | 委派给: py
  状态: pending_review | 轮次: 1/5

  验收标准:
    1. 代码实现完整
    2. 测试覆盖率 > 80%
    3. 有使用文档

  执行结果:
    已创建 optical_flow.py
    已创建 test_optical_flow.py
    测试通过率 100%

═══════════════════════════════════════════════════════════

  操作选项:
    r. 验收任务
    d. 删除任务
    h. 查看历史
    q. 返回列表
```

### 4. 快捷操作

在任务管理面板中：
- **输入序号**：查看任务详情
- **输入 n**：创建新委派（交互式）
- **输入 q**：退出

在任务详情页中：
- **r**：验收待验收任务
- **d**：删除任务（委托者）
- **h**：查看迭代历史
- **q**：返回列表

### 5. 智能提示

- 自动提示待验收任务数量
- 状态图标直观显示：
  - ✓ 已完成
  - ✗ 已失败
  - ⏳ 待验收
  - 🔄 执行中
  - ● 已接受
  - ○ 待处理

## 使用流程

### 场景1：查看和管理任务
```bash
> /collab
# 查看所有任务
# 选择任务查看详情
# 进行验收、删除等操作
```

### 场景2：创建新委派
```bash
> /collab
# 输入 n
# 进入交互式委派创建
# AI 自动生成验收标准
```

### 场景3：验收任务
```bash
> /collab
# 选择待验收任务
# 输入 r
# 查看 AI Review 总结
# 确认通过或驳回
```

### 场景4：查看历史
```bash
> /collab
# 选择任务
# 输入 h
# 查看所有迭代历史
```

## 其他命令

虽然 `/collab` 默认进入任务管理，但仍支持快捷命令：

- `/collab status` - 查看协作状态
- `/collab messages` - 查看消息
- `/collab delegate` - 直接创建委派

## 设计理念

1. **一站式管理**：所有操作都在任务管理面板完成
2. **智能提示**：自动提醒待验收任务
3. **简洁界面**：清晰的图标和布局
4. **集成操作**：查看、验收、删除、历史，一站式完成

## 完整的委派协作流程

```
1. /collab → 任务管理面板
2. 输入 n → 创建委派
3. AI 生成验收标准
4. 任务自动执行
5. /collab → 看到待验收提示
6. 选择任务 → 输入 r → 验收
7. 通过/驳回
8. 查看历史（输入 h）
```

整个流程闭环，信息完整，操作便捷！
