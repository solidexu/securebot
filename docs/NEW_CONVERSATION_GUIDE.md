## 🎯 设计理念

**以任务为核心，而不是以每个 agent 为核心**

```
传统模式：
  窗口1 (dev) → 委托者操作
  窗口2 (py)  → 被委托者操作
  需要切换窗口

协作会话模式：
  协作会话界面（群聊）
  ├─ 委托者和被委托者都在同一个界面
  ├─ 所有操作在一个界面完成
  ├─ @py 触发自动接受
  └─ 决策请求闪烁提示
```
