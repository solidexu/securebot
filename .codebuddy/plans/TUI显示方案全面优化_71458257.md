## 需求概述

用户希望参考 deerflow、opencode、claude_code 等项目的实现方案，对当前 TUI 显示系统进行全面优化，包括：

### 核心问题

1. **代码写入动画不滚动**：只显示前几行，不会继续更新后面几行
2. **exec 执行过程缺少 shell 形式显示**：当前只显示最终结果，无实时流式输出
3. **整体对话显示方案需要优化**：缺少虚拟化、缓存机制

### 调研发现

- **Claude Code**：完全自定义 Ink 渲染引擎，使用差异化渲染、虚拟列表、流式渲染管道
- **OpenCode**：Go 语言 + Bubble Tea 框架，Elm 架构的事件驱动模式
- **DeerFlow**：SSE 流式响应，Web 可视化界面
- **ink-virtual-list**：虚拟化列表组件，只渲染可见区域

## 技术方案

### 一、核心架构参考

```
Claude Code 渲染管线：
React JSX → Reconciler → Ink DOM → Yoga布局 → 差异更新 → ANSI序列 → 终端输出
```

**关键技术**：

- 差异化渲染：只更新变化的单元格
- 虚拟列表：只渲染视口内内容
- 帧率控制：约16ms/帧（60fps）
- 流式渲染：实时处理 LLM 响应

### 二、问题根因分析

#### 代码写入动画问题

**根因**：`setInterval` 在 Ink 环境中不稳定

- Ink 使用自定义 Reconciler，状态更新可能被批处理
- `useRef` 变化不触发渲染，即使使用 `editorVersion` 计数器
- `syncToState()` 创建新数组的时机可能在同一渲染周期被合并
- 滚动窗口的 `windowStart` 依赖 `currentLine`，更新延迟导致窗口不动

#### exec 执行问题

**根因**：`spawn` 收集完输出才返回

- 没有实时推送 stdout/stderr 到 TUI
- 缺少 Shell 面板组件
- 无流式输出机制

### 三、优化方案

#### 方案1：帧驱动动画系统

创建 `AnimationManager` 类，替代 setInterval：

```typescript
// 核心思路：使用 requestAnimationFrame 风格
class AnimationManager {
  private frameId: number | null = null;
  private lastTime: number = 0;
  private targetFps: number = 30; // 30fps = 33ms/帧
  
  // 使用 setTimeout 而非 setInterval（更可控）
  tick(callback: (deltaTime: number) => void) {
    const now = Date.now();
    const delta = now - this.lastTime;
    if (delta >= 1000 / this.targetFps) {
      callback(delta);
      this.lastTime = now;
    }
    this.frameId = setTimeout(() => this.tick(callback), 16);
  }
}
```

#### 方案2：虚拟化滚动窗口

```typescript
// 只渲染可见区域 + 缓冲区
const BUFFER_LINES = 2; // 上下各缓冲2行
const windowStart = Math.max(0, currentLine - Math.floor(EDITOR_LINES / 2) - BUFFER_LINES);
const windowEnd = Math.min(totalLines, windowStart + EDITOR_LINES + BUFFER_LINES * 2);
const visibleLines = displayLines.slice(windowStart, windowEnd);
```

#### 方案3：状态分离

```typescript
// 分离动画状态和显示状态
interface AnimationState {
  currentLine: number;
  isPlaying: boolean;
  speed: number;
}

interface DisplayState {
  windowStart: number;
  visibleLines: DisplayLine[];
  cursorPosition: number;
}
```
