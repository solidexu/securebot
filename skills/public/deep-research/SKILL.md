# 深度研究技能

## 概述

此技能提供系统化的网络研究方法论。在开始任何内容生成任务前，先加载此技能以确保从多个角度、深度和来源收集足够信息。

## 何时使用

### 研究类问题
- 用户问"什么是X"、"解释X"、"研究X"、"调查X"
- 用户想深入了解某个概念、技术或主题
- 问题需要来自多个来源的最新、全面信息
- 单次网络搜索不足以正确回答

### 内容生成（预研究）
- 创建演示文稿（PPT/幻灯片）
- 创建前端设计或 UI 原型
- 撰写文章、报告或文档
- 制作视频或多媒体内容
- 需要真实世界信息、示例或当前数据的任何内容

## 核心原则

**永远不要仅凭通用知识生成内容。** 输出质量直接取决于之前研究的质量和数量。单次搜索查询永远不够。

## 研究方法论

### 阶段一：广泛探索

从广泛搜索开始了解全貌：

1. **初步调研**：搜索主主题了解整体背景
2. **识别维度**：从初步结果中识别需要深入探索的子主题、主题、角度或方面
3. **绘制版图**：记录存在的不同观点、利益相关者或视角

示例：
```
主题："AI 在医疗领域"
初步搜索：
- "AI 医疗应用 2024"
- "人工智能医学诊断"
- "医疗 AI 市场趋势"

识别维度：
- 诊断 AI（放射学、病理学）
- 治疗推荐系统
- 行政自动化
- 患者监护
- 监管环境
- 伦理考量
```

### 阶段二：深入挖掘

对识别的每个重要维度进行针对性研究：

1. **具体查询**：针对每个子主题使用精确关键词搜索
2. **多种表述**：尝试不同的关键词组合和表述方式
3. **获取完整内容**：阅读重要来源的完整内容，而非仅片段
4. **跟踪引用**：当来源提到其他重要资源时，也搜索那些内容

### 阶段三：多样性与验证

通过寻求多样化信息类型确保全面覆盖：

| 信息类型 | 目的 | 示例搜索 |
|---------|------|---------|
| **事实与数据** | 具体证据 | "统计"、"数据"、"数字"、"市场规模" |
| **示例与案例** | 真实应用 | "案例研究"、"示例"、"实现" |
| **专家观点** | 权威视角 | "专家分析"、"访谈"、"评论" |
| **趋势与预测** | 未来方向 | "趋势"、"预测"、"未来" |
| **比较** | 背景和替代方案 | "vs"、"比较"、"替代" |
| **挑战与批评** | 平衡观点 | "挑战"、"局限"、"批评" |

### 阶段四：综合检查

在进入内容生成前，验证：

- [ ] 我是否从至少 3-5 个不同角度进行了搜索？
- [ ] 我是否获取并阅读了最重要的来源完整内容？
- [ ] 我是否有具体数据、示例和专家观点？
- [ ] 我是否探索了正面方面和挑战/局限？
- [ ] 我的信息是否来自权威来源且是最新的？

**如果任何答案是否定的，继续研究后再生成内容。**

## 搜索策略技巧

### 有效查询模式

```
# 带上下文的具体化
❌ "AI 趋势"
✅ "企业 AI 采用趋势 2024"

# 包含权威来源提示
"[主题] 研究论文"
"[主题] 行业报告"
"[主题] 专家分析"

# 搜索特定内容类型
"[主题] 案例研究"
"[主题] 统计数据"
"[主题] 最佳实践"

# 使用时间限定词
"[主题] 最新"
"[主题] 近期发展"
```

## 质量标准

当你能自信回答以下问题时，研究是充分的：
- 关键事实和数据点是什么？
- 2-3 个具体真实世界示例是什么？
- 专家对这个主题怎么说？
- 当前趋势和未来方向是什么？
- 有哪些挑战或局限？
- 这个主题为何现在相关或重要？

## 常见错误

- ❌ 1-2 次搜索后就停止
- ❌ 依赖搜索片段而不阅读完整来源
- ❌ 仅搜索多面主题的一个方面
- ❌ 忽略矛盾观点或挑战
- ❌ 使用过时信息而当有当前数据时
- ❌ 研究完成前就开始内容生成
