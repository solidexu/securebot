# 深度研究技能

提供系统化的网络研究方法论。在开始任何内容生成任务前，先加载此技能以确保从多个角度、深度和来源收集足够信息。

## 何时使用

### 研究类问题
- 用户问"什么是X"、"解释X"、"研究X"、"调查X"
- 用户想深入了解某个概念、技术或主题
- 问题需要来自多个来源的最新、全面信息

### 内容生成（预研究）
- 创建演示文稿（PPT/幻灯片）
- 撰写文章、报告或文档
- 需要真实世界信息、示例或当前数据

## 核心原则

**永远不要仅凭通用知识生成内容。** 输出质量直接取决于之前研究的质量和数量。

## 研究方法论

### 阶段一：广泛探索

1. **初步调研**：搜索主主题了解整体背景
2. **识别维度**：从初步结果中识别需要深入探索的子主题
3. **绘制版图**：记录存在的不同观点、利益相关者或视角

### 阶段二：深入挖掘

1. **具体查询**：针对每个子主题使用精确关键词搜索
2. **多种表述**：尝试不同的关键词组合和表述方式
3. **获取完整内容**：阅读重要来源的完整内容
4. **跟踪引用**：搜索来源提到的其他重要资源

### 阶段三：多样性与验证

| 信息类型 | 目的 | 示例搜索 |
|---------|------|---------|
| **事实与数据** | 具体证据 | "统计"、"数据"、"市场规模" |
| **示例与案例** | 真实应用 | "案例研究"、"示例" |
| **专家观点** | 权威视角 | "专家分析"、"访谈" |
| **趋势与预测** | 未来方向 | "趋势"、"预测" |

### 阶段四：综合检查

- [ ] 我是否从至少 3-5 个不同角度进行了搜索？
- [ ] 我是否有具体数据、示例和专家观点？
- [ ] 我的信息是否来自权威来源且是最新的？

## 搜索策略

```bash
# 带上下文的具体化
❌ "AI 趋势"
✅ "企业 AI 采用趋势 2024"

# 包含权威来源提示
"[主题] 研究论文"
"[主题] 行业报告"
```

## 常见错误

- ❌ 1-2 次搜索后就停止
- ❌ 依赖搜索片段而不阅读完整来源
- ❌ 仅搜索多面主题的一个方面
