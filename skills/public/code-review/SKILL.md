# 代码审查技能

专业的代码审查，帮助发现代码问题和改进建议。

## 何时使用

- 用户请求代码审查
- 检查代码质量
- 获取改进建议
- Pull Request 审查

## 审查维度

### 1. 代码质量

| 检查项 | 说明 |
|--------|------|
| 可读性 | 变量/函数命名是否清晰 |
| 一致性 | 代码风格是否一致 |
| 简洁性 | 是否有冗余代码 |
| 注释 | 注释是否充分 |

### 2. 正确性

| 检查项 | 说明 |
|--------|------|
| 逻辑错误 | 条件判断、循环逻辑是否正确 |
| 边界条件 | 是否处理了边界情况 |
| 错误处理 | 异常是否被正确捕获 |

### 3. 安全性

| 检查项 | 说明 |
|--------|------|
| 输入验证 | 用户输入是否经过验证 |
| 注入风险 | 是否有 SQL 注入、XSS 等风险 |
| 敏感数据 | 密码、密钥是否被正确处理 |

### 4. 性能

| 检查项 | 说明 |
|--------|------|
| 算法复杂度 | 是否使用了低效算法 |
| 内存使用 | 是否有内存泄漏 |
| 数据库查询 | SQL 是否优化 |

## 工作流程

1. **理解上下文**：了解代码的目的和功能
2. **快速浏览**：获取代码整体结构
3. **详细审查**：按维度逐一检查
4. **生成报告**

## 输出格式

```markdown
# 代码审查报告

## 概述
[代码的整体评价]

## 发现的问题

### 严重问题 (必须修复)
1. [问题描述]
   - 位置: file.py:123
   - 建议: [具体建议]

## 优点
[代码做得好的地方]
```
