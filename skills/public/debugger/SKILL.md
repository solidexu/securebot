# 调试技能

系统化地识别和解决代码中的 bug、错误和异常行为。

## 何时使用

- 分析错误消息和堆栈跟踪
- 调试失败的测试
- 调查运行时问题
- 排查生产事故
- 内存泄漏检测

## 调试流程

### 1. 复现问题

- 确定重现问题的确切步骤
- 记录预期行为 vs 实际行为
- 收集相关日志和错误消息

### 2. 隔离问题

- 使用二分查找缩小代码范围
- 检查最近的代码变更（git diff/blame）
- 检查相关配置

### 3. 分析根因

- 仔细阅读堆栈跟踪
- 检查断点处的变量状态
- 检查错误处理逻辑

### 4. 修复并验证

- 实现修复
- 添加测试用例
- 验证没有回归

## 常用调试技术

| 技术 | 用途 |
|------|------|
| **日志** | 添加战略性日志语句 |
| **打印调试** | 快速变量检查 |
| **断点** | 逐步执行代码 |
| **断言** | 验证假设 |

## 输出格式

```markdown
问题: [问题描述]
根因: [分析]
解决方案: [修复代码]
预防措施: [如何避免]
```
