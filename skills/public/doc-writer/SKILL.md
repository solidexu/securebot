# 文档撰写

创建清晰、全面、结构良好的文档。

## 何时使用

- 编写 README 文件
- 创建 API 文档
- 编写用户指南和教程
- 记录代码和架构

## 文档类型

### README
- 项目概述和目的
- 安装说明
- 快速开始指南
- 使用示例

### API 文档
- 端点描述
- 请求/响应格式
- 认证要求
- 错误码
- 多语言代码示例

### 用户指南
- 分步教程
- 截图和图表
- 故障排除部分

## 写作指南

1. **清晰**：使用简单直接的语言
2. **完整**：覆盖所有必要信息
3. **最新**：保持文档更新
4. **一致**：遵循一致的风格
5. **示例**：展示，而不只是讲述

## 输出格式

使用适当的 Markdown 格式：
- 标题组织结构
- 带语言标签的代码块
- 表格展示结构化数据
- 列表展示枚举
